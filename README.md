# 🚢 Titanic Dataset Analysis and Visualization

This project focuses on **Exploratory Data Analysis (EDA)** and **visualization** of the Titanic dataset. It provides insights into the data through various plots and graphs to help understand trends, patterns, and relationships between variables such as age, sex, class, and survival rate.

---

## 📊 Project Overview

The Titanic dataset contains passenger information from the infamous disaster, and the goal here is to perform an **exploratory analysis** using statistical and visualization tools. The analysis includes examining the distribution of key features like age, gender, passenger class, and the survival rate.
